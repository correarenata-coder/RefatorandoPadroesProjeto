## 📌 Simple Factory

Contexto: O padrão **Simple Factory** é uma variação do padrão Factory, onde uma única classe é responsável por criar objetos de diferentes tipos com base em algum critério. Ele é considerado um padrão de criação, mas não é um padrão de projeto formalmente reconhecido pela Gang of Four (GoF). O Simple Factory é frequentemente usado para encapsular a lógica de criação de objetos e fornecer uma interface simples para os clientes.
